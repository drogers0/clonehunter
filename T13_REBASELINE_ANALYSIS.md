## Performance note (not a correctness issue)
Cold embedding is slow on candle CPU (~18 min/large repo) — a **known, documented candle limitation** (candle #2877: ~8.5× slower than PyTorch even with mkl, on our exact model family + version), not a CloneHunter bug. CloneHunter's own logic is faster than Python (similarity 0.32s vs 1.43s). Embedding is a one-time cached cost (warm ≈ 1s). Opt-in `metal` feature gives ~4.6× (241s vs 1108s on click) with unvalidated GPU numerics; `accelerate`/`mkl` did not help (candle's bottleneck is per-op overhead, not BLAS).
